# HavoUz — Weather for Uzbekistan and the world

An interactive, responsive weather app for Uzbekistan and cities around the world.

**Live demo:** [havouz.netlify.app](https://havouz.netlify.app/) · **Interface languages:** Uzbek, English, Russian

## Features

- Current weather and an hourly forecast in three-hour intervals
- Quick access to weather across Uzbekistan's regions
- Search for a city by name
- Browse weather for countries and cities, and save favorites
- Temperature, feels-like temperature, humidity, wind speed, and pressure
- Search for places on the map
- Light and dark themes saved in the browser
- Weather-specific backgrounds and a mobile-friendly layout

## Built with

- HTML, CSS, and JavaScript
- OpenWeather APIs for current weather, forecasts, and geocoding
- Google Maps embed for map locations

## Run locally

1. Clone or download this repository.
2. Open `index.html` in a browser.

The app needs an OpenWeather API key to load weather data. The current client-side app makes API requests from the browser. Do not put a private credential in public source code; use a server-side proxy for a production deployment.
