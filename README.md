# HavoUz — O‘zbekiston va dunyo ob-havosi

O‘zbekiston hududlari va dunyo shaharlari uchun ob-havo ma’lumotlarini ko‘rsatuvchi interaktiv, moslashuvchan web ilova.

**Demo:** [havouz.netlify.app](https://havouz.netlify.app/) · **Til:** O‘zbekcha, English, Русский

## Imkoniyatlar

- Toshkentdan boshlab joriy ob-havo va 3 soatlik oraliqlarda soatlik prognoz
- O‘zbekiston hududlari ob-havosiga tez o‘tish
- Shahar nomi bo‘yicha qidirish
- mamlakat va shaharlardagi ob-havoni ko‘rish va sevimlilarni saqlash
- Harorat, his qilinadigan harorat, namlik, shamol tezligi va bosim
- Xarita orqali joy qidirish
- Yorug‘ va qorong‘i ko‘rinish; tanlovlar brauzerda saqlanadi
- Ob-havo holatiga mos ranglar va mobil ekranlarga mos dizayn

## Texnologiyalar

- HTML, CSS va JavaScript
- OpenWeather API — joriy ob-havo, prognoz va geokodlash
- Google Maps embed — xaritadagi joylashuv

## Ishga tushirish

1. Repozitoriyani yuklab oling.
2. `index.html` faylini brauzerda oching.

Ilova ob-havo ma’lumotlarini olish uchun OpenWeather API kalitidan foydalanadi. Ommaviy repoga haqiqiy kalitni joylamang; ishlab chiqarish muhiti uchun kalitni server orqali xavfsiz uzatish kerak.

## Hissa qo‘shish

Xatolar va takliflar uchun [issue oching](https://github.com/yaqubovmehmed/HavoUz/issues).

# HavoUz — Weather for Uzbekistan and the world

An interactive, responsive weather app for Uzbekistan and cities around the world.

**Live demo:** [havouz.netlify.app](https://havouz.netlify.app/) · **Languages:** Uzbek, English, Russian

Features include current conditions, hourly forecasts, city search, Uzbekistan region shortcuts, country favorites, map-based location search, metric weather details, and light/dark themes. Built with HTML, CSS, and JavaScript using OpenWeather APIs and a Google Maps embed.
